# Code Description

This project is a **modern, responsive multi-page corporate website** inspired by the Amul brand. It demonstrates how to build a professional business website using **HTML, CSS, and JavaScript**, focusing on responsive layouts, clean UI/UX, and interactive web components.

### Overview

The website begins with a fully responsive navigation bar that provides seamless access to multiple pages, including **Home, About, Services, Products, and Contact**.

The homepage showcases the brand through visually appealing sections, service highlights, product information, and smooth design elements that enhance the overall user experience.

The **Services** page presents Amul's core offerings, including milk collection, dairy product distribution, farmer support, and retail services using modern card-based layouts and responsive components.

The **Contact** page features an interactive contact form powered by **EmailJS**, allowing visitors to send messages directly without requiring a backend server. It also includes **city autocomplete suggestions**, making location input faster and more user-friendly.

To improve accessibility and usability, the project integrates **Google Maps**, allowing users to quickly locate the company headquarters. A continuously scrolling logo slider highlights trusted partner brands and enhances the visual appeal of the website.

The project follows a clean and modular structure, making it easy to maintain, customize, and extend for future business requirements.
