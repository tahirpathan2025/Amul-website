# 🥛 Amul Digital Experience

A modern and responsive multi-page corporate website inspired by the Amul brand. The project showcases a clean and user-friendly interface with interactive features, responsive layouts, contact form integration, and modern web design principles.

---

## 🚀 Features

- Responsive Design
- Multi-Page Website
- Modern Navigation Bar
- Beautiful Hero Sections
- Company Information
- Services Showcase
- Contact Page
- EmailJS Contact Form
- Google Maps Integration
- City Autocomplete Search
- Animated Logo Slider
- Professional Footer
- Mobile Friendly Layout
- Clean UI/UX
- Optimized Images

---

## 📂 Pages

- Home
- About Us
- Services
- Products
- Contact
